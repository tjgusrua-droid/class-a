# 영진위 서울 극장 데이터 검증 정리

- `scripts/verify_kofic_seoul.py`: 목록 수와 총계 시트 대조, 중복 점검 → `kofic_seoul_report.md`
- `scripts/build_seoul_theaters.py`: 연도별 상태표를 만들고 파일 오류 목록 생성 → `file_errors.md`, `data/clean/*.csv`

## 집계 규칙

| 구분 | 처리 |
|---|---|
| 영업 | 그해 본 목록에 있는 극장 → **포함** |
| 신규개관 | 본 목록에 이미 들어 있음 → **포함**(이중 집계 없음) |
| 휴관 | 본 목록에는 없고 휴폐관 목록에만 있음 → **포함**, `status=휴관` |
| 폐관 / 브랜드 전환(옛 이름) | **제외** |
| 부분 폐관(n관) | 극장 상태는 그대로 두고 이벤트로만 기록 |
| 본 목록과 휴폐관 목록에 동시 등장 | 한 극장으로 합침(본 목록 우선) |
| 기록 없이 휴관 지속 | 2년까지만 휴관으로 보고 이후는 실질 폐관 처리(영진위 기준) |

## 확인된 사항

1. **중복 없음.** 본 목록의 극장·스크린 수가 16년 모두 총계 시트와 일치하고, 같은 극장이 두 번 나오는 경우가 없다. 2014년 전국 시트의 `메가박스 동대문` 중복은 서울 시트로 대체했다.
2. **서울아트시네마는 세 번 이전했다.** 낙원상가 4층(2010~2014) → 서울극장 3층(2015~2021) → **중구 정동길 3 경향아트힐 2층(2022~)**. 행정안전부 CSV도 같다: 2022-03-24 관수동 폐업, 2022-03-23 정동 신규 인허가(지번 정동 22, 경향신문사). 따라서 "한 건물에 극장 3곳"은 2015~2021년 서울극장 건물에만 해당하고, 2025년 현재는 해당하지 않는다.
   - 2025년 현재 한 주소에 두 극장이 있는 곳: 낙원상가(허리우드 클래식·낭만극장), 양화로 176(롯데시네마 홍대입구·인디스페이스), 동작대로 89(메가박스 이수·아트나인). 모두 별개 극장이다.
   - 같은 건물(정동 22)에는 2010년 폐관한 `시네마 정동`도 있었다.
3. **본 목록은 휴관 극장을 뺀다.** 2010년 총계 시트 각주("2년 미만 휴관 극장은 명부에 포함")와 실제 목록이 다르다. 실제로는 아리랑시네센터(2013), 롯데시네마 월드타워(2014) 같은 휴관 극장이 본 목록에서 빠져 있다.

## 파일 오류 (상세는 `file_errors.md`)

- 2010년: 부록 제목이 `2011년 개관 극장`(KU 시네마테크). 2011년 본 목록부터 나온다.
- 2011년: 휴폐관 구역이 비어 있다. 그런데 7곳(CF21씨네마, CGV 문래, 씨네시티, 아산 M 단성사, 크링시네마, 프리머스시네마 신림, 하이퍼텍나다)이 기록 없이 사라졌다. 같은 해 씨너스→메가박스 같은 브랜드 전환 10여 건은 주소로 짝지어 `전환(목록비교)`로 처리했다.
- 2013년: 부록 제목이 `2012 휴폐관 극장`(연도 오기).
- 2019년: 신규개관·휴폐관 시트가 없다. 2018·2020년 목록과 비교해 추정했다.
- 기록 없이 사라진 극장: 2013 메가박스 서울대, 2014 CGV 독산·CGV 프라임신도림·롯데시네마 가산하이힐, 2021 씨네Q 성신여대입구, 2022 CGV 목동.
- 신규개관 시트에 없는데 새로 나온 극장: 2022 메가박스 더 부티크 목동현대백화점, 2024 픽처하우스.
- 기록 없는 이름 변경: 2024 롯데시네마→메가박스 브로드웨이(신사), 2025 CGV영등포→CGV영등포타임스퀘어.
- 2023년 이후 휴폐관 시트에 `n관` 단위 행이 섞여 있다(부분 폐관으로 분리 처리).

## 수동 보정

확인된 사실은 `data/manual/corrections.csv`에 한 줄씩 적고 `python3 scripts/build_seoul_theaters.py`를 다시 돌린다.
- `rename`: 이름·운영 주체 변경(같은 극장의 계보). 옛 이름의 폐관을 전환으로 바꾸고 휴관 중복 행을 지운다.
- `close`: 폐관 날짜 확정(행안부 폐업일자 등)
- `address`: 주소 교체
해결된 오류는 `file_errors.md` 맨 아래 "수동 보정으로 해결됨"으로 옮겨진다.
