# 로또 6/45 역대 당첨번호 데이터

`lotto_history.json`은 1회(2002-12-07)부터 최신 회차까지의 로또 6/45 당첨번호 기록입니다.

## 출처

동행복권 공식 추첨 결과를 정리해 공개한 [smok95/lotto](https://github.com/smok95/lotto)
저장소의 `results/all.json`을 가공했습니다. `scripts/build_lotto_data.py`로 재생성할 수 있습니다.

## 스키마

각 원소는 한 회차를 나타내며 필드는 다음과 같습니다.

| 필드 | 의미 |
|---|---|
| `n` | 회차 번호 |
| `d` | 추첨일 (`YYYY-MM-DD`) |
| `k` | 당첨번호 6개 (오름차순) |
| `b` | 보너스 번호 |

```json
{"n":1,"d":"2002-12-07","k":[10,23,29,33,37,40],"b":16}
```
