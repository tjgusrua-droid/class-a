# 로또 6/45 역대 당첨번호 데이터

`lotto_history.json`은 1회(2002-12-07)부터 최신 회차까지의 로또 6/45 당첨번호 기록입니다.

## 출처

동행복권 공식 추첨 결과를 정리해 공개한 [smok95/lotto](https://github.com/smok95/lotto)
저장소의 `results/all.json`을 가공했습니다. `scripts/build_lotto_data.py`로 재생성할 수 있습니다.

## 스키마

각 원소는 한 회차를 나타내며 필드는 다음과 같습니다.

| 필드 | 의미 |
|---|---|
| `n` | 회차 번호 |
| `d` | 추첨일 (`YYYY-MM-DD`) |
| `k` | 당첨번호 6개 (오름차순) |
| `b` | 보너스 번호 |

```json
{"n":1,"d":"2002-12-07","k":[10,23,29,33,37,40],"b":16}
```

# 1등 배출 판매점 데이터

`lotto_stores.json`은 262회부터 최신 회차까지 공개된 1등 배출 판매점 기록을 집계한 것입니다.
같은 [smok95/lotto](https://github.com/smok95/lotto) 저장소의 `winning-stores/`를 가공했으며,
`scripts/build_store_data.py`로 재생성할 수 있습니다.

| 키 | 의미 |
|---|---|
| `meta` | 수집 회차 범위, 총 기록 수, 고유 판매점 수, 인터넷 판매 1등 횟수, 선택 방식(자동/수동/반자동) 분포 |
| `regions` | 시·도별 1등 배출 횟수 |
| `stores` | 3회 이상 배출한 판매점 목록 — `n` 상호, `a` 주소, `r` 시·도, `w` 배출 횟수, `lat`/`lng` 좌표 |

원본 데이터의 알려진 흠:

- 주소 접두사 `전남광주`는 `광주광역시`의 오타입니다(좌표로 확인). 집계 시 광주로 합칩니다.
- `세븐일레븐 홍익점`(경기 안성)의 경도가 `12.23889`로 잘못 기록되어 있어 지도에 찍히지 않습니다.
- 1~261회는 판매점 정보가 공개되지 않았고, 289·295·463·1198회는 원본에 기록이 비어 있습니다.

# 전국 시·도 경계

`korea_provinces.json`은 통계청 2018년 시·도 경계
([southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps), CC BY-SA)를
SVG 경로로 단순화한 것입니다. `scripts/build_korea_map.py`로 재생성합니다.
본토와 제주가 화면을 채우도록 표시 범위를 고정했기 때문에 울릉도·독도·백령도는 지도에 포함되지 않습니다.
`projection` 값으로 위경도를 같은 좌표계에 투영할 수 있습니다.
