# 박스오피스 평일 / 주말 / 공휴일 비교

영화진흥위원회(KOBIS) 일별 박스오피스를 받아서
**평일 · 주말 · 공휴일의 일평균 관객수**를 비교하고 HTML 차트를 만듭니다.

파이썬 3만 있으면 되고, 설치할 패키지는 없습니다.

## 쓰는 법

### 1. 데이터 받기

```bash
export KOBIS_KEY=발급받은키
python3 fetch.py --start 2024-09-01 --end 2025-08-31
```

하루에 한 번씩 요청하므로 1년치는 365번 호출합니다 (몇 분 걸림).
받은 원본은 `cache/` 에 저장돼서, 중간에 끊겨도 다시 돌리면 이어서 받습니다.
결과는 `daily.csv`.

### 2. 공휴일 목록 확인

`holidays_kr.txt` 를 열어서 분석할 기간의 공휴일이 맞는지 봐주세요.
**이 목록은 손으로 적은 거라 검증이 필요합니다.** 대체공휴일·임시공휴일이
해마다 바뀌니, 공공데이터포털 "특일 정보" API 나 달력으로 대조하는 걸 권합니다.
틀린 게 있으면 이 파일만 고치면 되고 코드는 안 건드려도 됩니다.

### 3. 분석 + 차트

```bash
python3 analyze.py                        # 관객수 기준
python3 analyze.py --metric sales_top10   # 매출액 기준
```

`report.html` 이 생깁니다. 브라우저로 열면 됩니다 (다크모드·모바일 대응,
막대에 마우스 올리면 상세값). 터미널에도 요약이 찍힙니다.

## 집계 규칙

- **공휴일이 주말보다 우선.** 토요일에 낀 추석은 "공휴일"로만 셉니다.
  (안 그러면 주말 평균이 공휴일 효과로 부풀려짐)
- **요일별 차트에서는 공휴일을 제외.** 공휴일은 따로 집계하니까요.
- 평균과 함께 **중앙값**도 봅니다. 박스오피스는 대형 흥행작 한 편에
  크게 흔들려서 평균만 보면 오해하기 쉽습니다.

## 숫자 읽을 때 주의

KOBIS 일별 박스오피스는 **그날 상위 10편만** 줍니다.
그래서 여기서 말하는 "일별 관객수"는 그날 **전체** 관객수가 아니라
**top 10 합계**입니다. 보통 전체의 90% 이상이라 평일/주말 비율 비교에는
충분하지만, 절대값을 "그날 전체 관객수"라고 말하면 안 됩니다.
